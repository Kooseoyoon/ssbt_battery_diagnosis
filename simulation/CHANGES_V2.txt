V2 변경 기록 — 2026-11-05

목적
첫 파일럿에서 확인된 수명 예측 오차와 예측구간 과신을 개선할 후보를 구현하고,
각 변경의 성능을 동일 조건의 기존 모델과 비교한다. 개선 성공 여부는 실행 후 판단한다.

1. 평가 구조
기존: 86개 후보 전체에서 학습하지 않은 국소 선형모델과 검사 전략을 비교.
변경: 외부 2-fold, 분할 시드 11/29/47. 각 fold는 개발 43셀 + 평가 43셀.
개발 43셀 중 32셀에서 3-fold 내부 교차검증으로 설정을 선택하고 학습,
별도 11셀로 예측구간을 보정한다. 평가 셀은 이 과정에 쓰지 않는다.
평가 후보 43개로 8셀 팩 5개를 구성하고 3개는 미사용 후보로 남긴다.
86셀의 모든 셀이 각 분할 시드에서 평가에 한 번씩 들어간다.

2. 수명 예측
기존 모델(최근 최대 8개 관측 선형 외삽)을 동일 평가 집합에서 다시 계산한다.
전체 관측 선형 외삽도 비교하여 관측 창의 영향을 따로 본다.
새 모델은 관측된 용량·용량 감소·초기/최근 기울기 등 10개 특징으로 log RUL을 예측한다.
Ridge의 alpha 4개와 GP의 고정 RBF/잡음 조합 4개를 개발 데이터에서 비교한다.
평가의 미래 기록, EOL, 최종 기록 길이, protocol_id는 특징에 넣지 않는다.
학습 모델의 점예측은 exp(log RUL 평균), 즉 lognormal 중앙값이다.
기존 모델은 이전 코드의 RUL 샘플 평균을 그대로 사용한다. 이 차이도 변경에 포함된다.

3. 불확실성
Ridge는 학습 잔차로 초기 분산을 정하고, GP는 예측 공동 공분산을 사용한다.
보정 11셀에서 표준화된 log RUL 잔차의 유한 표본 분위수로 80% 구간 반경을 정한다.
raw/calibrated에서 점예측은 유지하고 구간 폭·포함률을 비교한다.
보정 분포는 이후 팩 구성 시나리오에 사용한다. 희소한 보정 셀과 분포 차이에 따른 한계가 있다.
80% 구간에 대한 보정이며 시나리오 꼬리·셀 간 상관의 정확성까지 검증한 것은 아니다.

4. 팩 구성
점예측 정렬 구성과, 보정된 시나리오에서 기대 팩 수명 합계를 늘리는 셀 교환을 비교한다.
팩 사이 교환과 미사용 후보 교환을 포함하며 최대 10회 개선한다.
최적화용 시나리오 256개와 별도 예측 가치 검사용 2,048개를 사용한다.
시나리오 기대값 상승이 실제 성능 상승을 보장하지 않으므로 실제 정답으로 별도 평가한다.

5. 고정한 조건과 아직 평가하지 않은 것
초기 21사이클부터 41/61/81/101사이클까지 모든 평가 셀을 균등 관측한다.
EOL 기준 1.44 Ah와 팩 수명=min RUL, 팩 수명 합계 목적은 유지한다.
관측량별 검사 소모 수명과 평가 집합의 실제 비용을 기록한다.
새 예측모델의 효과를 분리하기 위한 실험이므로 새 적응형 검사·중단 정책은 이번 버전에서 평가하지 않는다.
95점 도달 또는 검사량 30% 절감 여부를 미리 가정하지 않는다.

6. 결과 해석
비교는 이번 실험의 동일한 평가 집합·관측량에서 재계산한 기준과 한다.
이전 86셀 풀 점수와 이번 43셀 풀 점수의 차이를 개선량으로 계산하지 않는다.
분할 시드 반복은 같은 86셀을 재사용하므로 독립 데이터셋의 신뢰구간이 아니다.
앞선 탐색에서 전체 데이터를 이미 살펴보았으므로 외부 미지 데이터 검증이라고 주장하지 않는다.
