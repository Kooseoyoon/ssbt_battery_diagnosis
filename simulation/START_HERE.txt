실행
  VS Code F5: V3. 새 실험 입력·준비 상태 확인
  VS Code F5: V3. 실제 용량 기준선 7개 예산 실행
  VS Code 작업: V3 전체 검증
  저장소 루트에서 실행: uv run --directory simulation python -m battery_sim.experiment_v3 --stage preflight
  검증: uv run --directory simulation python -m unittest discover -s tests -q
  기존 Stage2용 conda는 그대로 보존되어 있다. V3 환경에는 Stage2 전체 의존성을 설치하지 않았다.
  새 PyTorch 의존성은 simulation/pyproject.toml 및 uv.lock에서 관리한다.

  C_full 용량 모델 비교
    uv run --directory simulation python -m battery_sim.physics_experiment
    현재 OOF 전체 팩 V는 Current-only 3374.803785, GP 3200.856840,
    일반 NN 3288.566720, 물리제약 NN 3227.416120 Ah·cycles이다.
    이는 동일 86셀에서 생성한 탐색용 OOF 배정이지 독립 재고 일반화 성능이 아니다.
  ODE 잔차 PINN 비교
    uv run --directory simulation python -m battery_sim.constitutive_pinn
    최고 PINN은 sqrt-linear, 잔차 가중치 1.0, V=3348.210495 (Current-only 대비 -26.593290).
    각 후보 V는 OOF 탐색 결과이며 독립 재고 평가가 아니다.
