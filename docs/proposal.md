# SSBT 공모전 제출 신청서 — 팩 조립 결정 중심(Decision-Aware)의 사용 후 배터리 적응형 진단

## 주제

팩 조립 결정 중심(Decision-Aware)의 사용 후 배터리 적응형 진단

## 문제 정의

전기차에서 퇴역한 배터리는 ESS 등 2차 용도의 팩으로 재조립된다. 현재는 입고 시점 측정 용량을 기준으로 셀을 선별하지만, 직렬 팩의 수명은 가장 먼저 열화되는 셀이 결정하므로 실제로 필요한 정보는 각 셀의 기대수명이며, 이는 현재 용량으로부터 알 수 없다.

* Deep Sorting 연구(Wang et al., 2025): 퇴역 셀 86개, 30개월 시험. 비슷한 SOH 셀들의 2차 수명이 196\~1,916사이클로 약 10배 차이, 현재 용량-2차 수명 상관계수 0.097.
* 본 팀이 같은 데이터로 확인: 셀별 실제 수명을 알고 조립하면 현재 용량 기준 조립 대비 팩 성능이 4직렬 66%, 16직렬 177% 향상 (2차 사용 초기 206사이클 구간 예비 결과, 정보가 완벽할 때의 상한).
* 딜레마: 진단이 부족하면 수명이 다른 셀이 섞여 팩이 일찍 끝나고, 진단을 늘리면 재사용 경제성이 떨어짐.

## 선행연구와의 차별점

* Deep Sorting: 86개 셀 전수에 동일한 1회 완전충전 시험 적용, 전압·전류 곡선에서 108개 특징 추출. 용량 기반 대비 평균 수명 약 40% 향상. 한계: 모든 셀에 동일 시험 적용, 셀별 진단량 차등화 없음.
* Severson et al. 2019, Attia et al. 2020: 초기 사이클로 수명 예측, 시험시간 단축. 한계: 예측 정확도/충전 최적화가 목적이며, 예측 오차가 팩 조립 결과에 미치는 손해(regret)는 다루지 않음.
* 본 제안: 진단 성과를 예측 정확도 대신 팩 조립 결과(pack regret)로 평가. Pack regret = 셀별 실제 수명을 모두 알 때의 최적 조립과 현재 정보로 결정한 조립 사이의 팩 성능 차이. 팩 배정이 바뀔 수 있는 셀에 진단을 집중.

## 구현 방법

1. 특징 추출: 2차 사용 초기 몇 사이클에서 용량, 열화 기울기, dQ/dV 피크 특성, 내부저항, 온도 상승폭 추출. 진단량 = 셀별 관측 사이클 수.
2. 예측 모델: Gaussian Process로 셀별 용량 궤적을 확률분포로 예측(셀 수 수십\~수백 규모에 적합, 불확실성 직접 제공, 예측구간 커버리지 확인).
3. 적응형 진단: 예측 분포에서 시나리오 샘플링 → 시나리오별 팩 조립 반복 → 배정이 자주 바뀌는 셀부터 추가 진단 → 추정 regret이 충분히 작아지거나 배정이 안정되면 진단 종료. 종료 후 실제 regret이 허용치를 넘는 비율로 중단 기준 신뢰성 평가.
4. 검증(시뮬레이션): 공개 데이터 기반, 추가 진단은 숨겨둔 미래 사이클을 단계적으로 공개하는 방식으로 모사, 실제 regret은 사후 평가. 가상 팩 4/8/16직렬, 셀 하나라도 SOH 60% 도달 시 팩 수명 종료. Deep Sorting NMC 셀로 주 검증(예측 모델은 별도 데이터셋으로 학습, 검증셋과 분리), LFP 셀로 화학조성 일반화 확인.
5. 비교 대상: 현행 용량 기반 선별, Deep Sorting(저자 공개 코드 그대로 사용), 균등 배분 진단, 무작위 선택, 불확실성 우선 선택.
6. 평가 지표: 동일 수준 regret 달성에 필요한 진단량의 절감률(방법별 비교).

## 기대효과

* 기술: 모든 셀 정밀진단 대비 진단량 30% 이상 절감, pack regret 5% 이하 유지 목표. NMC/LFP 양쪽 검증으로 범용성 확보. 팩 크기별 진단 가치 정량화.
* 산업: 진단은 사용후 배터리 재사용 공정에서 가장 시간이 많이 드는 단계 → 처리 용량·경제성 개선. 기존 충방전 설비 데이터만 사용, 추가 장비 없이 선별 SW/BMS에 탑재 가능. 신품 셀 출하검사·셀 매칭에도 확장 가능.
* 사회: EU 배터리 규정(배터리 여권 등) 대응 비용 절감, 재사용 팩 수명 연장을 통한 자원 효율 개선.
