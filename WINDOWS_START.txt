처음 실행하기
1. ZIP을 Windows로 옮겨 새 폴더에 압축을 푼다. 기존 연구 폴더와 섞지 않는다.
2. VS Code로 ssbt_battery_diagnosis 폴더 또는 battery-research.code-workspace를 연다.
3. VS Code 터미널이 simulation에서 시작하면 cd ..로 저장소 루트로 이동한다.
   현재 폴더에 battery-research.code-workspace가 있으면 루트가 맞다.
4. PowerShell에서 uv --version으로 설치 상태를 확인한다.
   없다면: winget install --id=astral-sh.uv -e
   설치 후 VS Code와 터미널을 다시 연다.
   공식 안내: https://docs.astral.sh/uv/getting-started/installation/
5. 저장소 루트에서 아래 명령을 순서대로 실행한다.

uv sync --project simulation --frozen
uv run --directory simulation --frozen python -m unittest discover -s tests -q
uv run --directory simulation --frozen python -m battery_sim.experiment_v3 --stage preflight
uv run --directory simulation --frozen python -m battery_sim.experiment_v3 --stage controls

Python이 없다면 uv python install 3.12 후 다시 진행한다.
Mac의 .venv를 복사하지 않았다. 첫 명령이 Windows용 Python 환경을 만든다.
환경 설치에는 인터넷 연결이 필요하다.
